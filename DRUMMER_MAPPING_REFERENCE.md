## 🔧 **MAPPING SYSTEM ARCHITECTURE**

### **How It Works:**

```
User Selects: "Studio Groove Master"
       ↓
Mapping Layer: Looks up source_drummers = ["jeff_porcaro"]
       ↓
Admin Database: Queries drummer_style_vectors for jeff_porcaro
       ↓
Characteristics: Returns quantified style vector
       ↓
AI Generation: Applies Porcaro characteristics to generated pattern
       ↓
Result: Pattern with Jeff Porcaro's ghost notes, ride preference, etc.
```

### **Blend Example (Progressive Polymath):**

```
User Selects: "Progressive Polymath"
       ↓
Mapping: source_drummers = ["mike_portnoy", "danny_carey"]
         blend_weights = [0.6, 0.4]
       ↓
Database: Gets style vectors for both drummers
       ↓
Blend: odd_time_comfort = (portnoy_value * 0.6) + (carey_value * 0.4)
       ↓
Result: Hybrid of Portnoy's precision + Carey's tribal feel
```

## 📊 **QUANTIFIED CHARACTERISTICS**

Each drummer has a **style vector** with values 0.0-1.0:

```json
{
  "ghost_note_density": 0.85,      // How many ghost notes (0-1)
  "ride_preference": 0.75,         // Ride vs hi-hat preference
  "kick_syncopation": 0.60,        // Bass drum complexity
  "snare_backbeat_strength": 0.90, // How hard they hit 2 & 4
  "fill_frequency": 0.40,          // How often they fill
  "swing_comfort": 0.80,           // Swing vs straight feel
  "technical_precision": 0.95,     // Accuracy (1.0 = robotic)
  "dynamics_range": 0.85,          // Soft → loud variation
  "groove_pocket": 0.90            // How deep in the pocket
}
```

**Example - Jeff Porcaro (Studio Groove Master):**
- ghost_note_density: 0.90 (master of ghosts)
- ride_preference: 0.85 (loves ride cymbal)
- swing_comfort: 0.95 (shuffle king)
- groove_pocket: 0.95 (legendary pocket)

**Example - Gene Hoglan (Metal Atomic Clock):**
- technical_precision: 0.98 (machine-like)
- kick_syncopation: 0.95 (double bass master)
- swing_comfort: 0.10 (straight time only)
- dynamics_range: 0.40 (consistent volume)

## 🚀 **API USAGE**

### **List All Drummers:**
```python
from drummer_mapping_service import get_drummer_service

service = get_drummer_service()
drummers = service.list_drummers()

# Returns:
[
  {
    "id": "studio_groove_master",
    "display_name": "Studio Groove Master",
    "tagline": "Precision pocket playing...",
    "genre_tags": ["Jazz Fusion", "Pop", "Rock"],
    "icon": "🎩",
    "color": "#4F46E5",
    ...
  },
  ...
]
```

### **Get Drummer Characteristics:**
```python
characteristics = service.get_drummer_characteristics("rock_powerhouse")

# Returns John Bonham's style vector:
{
  "ghost_note_density": 0.50,
  "ride_preference": 0.30,
  "kick_syncopation": 0.85,  # Triplet master
  "groove_pocket": 0.90,     # Deep pocket
  "dynamics_range": 0.95,    # Huge dynamic range
  ...
}
```

### **Generate with Drummer:**
```python
params = service.get_generation_parameters(

    song_analysis={"tempo": 100, "swing_amount": 0.3}
)

{
  "style": "funk",              # Dennis Chambers → funk style

}
```
