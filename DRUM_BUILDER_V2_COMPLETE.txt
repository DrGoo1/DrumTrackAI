┌──────────────────────────────────────────────────────────────────────────────┐
│ 🤖 LLM INTEGRATION                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ LLM WORKFLOW ───────────────────────────────────────────────────────────────┐
│                                                                              │
│  1. USER CONTROLS                                                           │
│     ↓                                                                        │
│  2. BUILD COMPREHENSIVE PROMPT                                              │
│     • Musical context (section, tempo, style)                               │
│     • User intent (all 17 controls)                                         │
│     • Analytical data (SongMap, drummer profile)                            │
│     • Exact JSON schema specification                                       │
│     ↓                                                                        │
│  3. CALL OPENAI API                                                         │
│     • Model: gpt-4o-mini (default)                                          │
│     • Response format: JSON                                                 │
│     • Temperature: 0.7                                                      │
│     • Max tokens: 2048                                                      │
│     ↓                                                                        │
│  4. PARSE PERFORMANCE SPEC                                                  │
│     • Per-instrument profiles                                               │
│     • Per-phrase variations                                                 │
│     • Micro-timing arrays                                                   │
│     • Velocity curves                                                       │
│     ↓                                                                        │
│  5. APPLY TO PATTERN                                                        │
│     • Each note gets micro-timing offset                                    │
│     • Each note gets adjusted velocity                                      │
│     • Ghost/flam/drag probabilities applied                                 │
│     ↓                                                                        │
│  6. HIGH-RES MIDI OUTPUT                                                    │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ FALLBACK CHAIN ─────────────────────────────────────────────────────────────┐
│                                                                              │
│  1. TRY LLM                    → If OpenAI available                        │
│     ↓ (fails)                                                               │
│  2. USE ANALYTICS              → Drummer profile + user controls            │
│     ↓ (fails)                                                               │
│  3. USE FLAT SPEC              → No humanization                            │
│                                                                              │
│  ALWAYS PRODUCES OUTPUT ✅                                                   │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
